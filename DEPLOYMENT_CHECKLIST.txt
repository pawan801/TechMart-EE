DEPLOYMENT STEPS
===============================================

1. REBUILD THE PROJECT:
   Run: BUILD_AND_DEPLOY.bat
   Or:  mvn clean install

2. CHECK BUILD OUTPUT:
   Should create: techmart-ear/target/techmart-ear.ear

3. DEPLOY TO PAYARA:
   Option A: Use DEPLOY_TO_PAYARA.bat
   Option B: Use Payara Admin Console (GUI)
             - Go to http://localhost:4848
             - Applications → Deploy
             - Select: techmart-ear/target/techmart-ear.ear
   Option C: Manual asadmin command
             - asadmin deploy techmart-ear/target/techmart-ear.ear

4. VERIFY IN BROWSER:
   Open: http://localhost:8080/techmart-ear/products
